# Diabetes Dataset Comparison Analysis

This project compares **statistical summaries** and **regression model performance** between two diabetes datasets:
- **UCI Diabetes dataset** (`uci_diabetes.csv`)
- **Pima Indians Diabetes dataset** (`pmi_diabetes.csv`)

## 📌 Features
- Load precomputed statistics from CSV files
- Display summary statistics for both datasets
- Compare regression model performance:
  - Linear Regression R² scores
  - Logistic Regression accuracy scores

1. Place `uci_diabetes.csv` and `pmi_diabetes.csv` in the project directory.
